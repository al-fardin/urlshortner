Simple architecture

Three parts. One clear flow.

The frontend only sends and displays data. Go owns validation and redirects. The memory store keeps the short-code mapping while the server is running.

01 / Browser

Send the URL

JavaScript sends the long URL and optional alias as JSON to POST /api/shorten.

02 / Go handler

Validate & save

The handler validates the destination, chooses a code, then saves code → URL in memory.

03 / Redirect

Open the target

Visiting /:code finds the original URL and returns an HTTP 302 redirect.
